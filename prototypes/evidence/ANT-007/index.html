ANT-007 PROTOTYPE

운영 기록 분석 · 실험 검토 · 현장 전파 지침 (회계 연결 제외)

시나리오: 정상 운용
실시간 연결됨
갱신: -
검증 시나리오 즉시 주입:
데이터 파이프라인 연결 장애가 발생했습니다.
규칙: 조회 실패를 0건으로 표시하지 않음
원장 정제 경고: 동일 고객 또는 중복 발권 키가 감지되었습니다.
18건 중복

원장 데이터 파이프라인 품질 감시

정상 · 일부 누락 · 오래된 자료 · 확인 불가 4단계 분류 기준에 따라 데이터셋의 신뢰성을 실시간 모니터링합니다.

운영 실험 카드 (보호자 웰컴 음료 예시)

가설 수립부터 변경 내용, 대조 방식, 지표 측정, 표본 수 검증, 다음 결정까지 전 과정을 구조화해 관리합니다.

실증 원칙 준수 모드
1. 표본 부족 → 판단 보류

표본 수가 통계적 기준 미달 시 성공/실패 판정을 금지하고 '판단 보류'로 처리합니다.

2. 단순 전후 비교 → 관찰 결과

대조군이 없는 단순 전후 비교는 인과성 입증이 아닌 '관찰 결과'로 격리 표기합니다.

3. 비용 미입력 → 0원 처리 금지

원가 미입력 상태를 0원이나 수익성 검증 완료로 왜곡하지 않고 산정 보류로 남깁니다.

현장 전파용 표준 운영 지침 (Transferable Guidelines)

실증된 실험 결과를 바탕으로 적용 조건, 실행 절차(SOP), 한계점, 타 현장(영주·안동 등) 재검증 항목을 표준화합니다.
