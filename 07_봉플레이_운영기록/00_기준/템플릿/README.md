# 템플릿

- 기록 유형: 기준 · 생산자: 클로이 · 근거: 2026-11-11 대표 "이 템플릿 지켜서 작성" · 최종 확인일: 2026-11-17

| 파일 | 용도 |
|---|---|
| `회의록.html` | 운영회의록 확정본 (A4 2쪽) |
| `안건표.html` | 운영회의 안건표 (A4 2쪽, 결과 칸 비움) |
| `logo.svg` | BONG PLAY 로고 **임시 트레이스본**(원본 아님) |
| `render.js` | HTML → PDF 변환과 넘침 검사 |

글꼴은 Google Fonts(Jua, Noto Sans KR)를 불러오므로 인터넷 연결이 필요하다. 렌더: `node render.js 회의록.html 운영회의록_YYYY-MM-DD_확정.pdf`. 출력되는 `[본문 끝, 바닥글]`에서 본문 끝이 더 크면 간격을 줄인다.

제안서·경영원칙 등 내부용 문서의 디자인 기준은 `../작업기준/디자인_규칙.md` 0절.
