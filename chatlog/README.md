# 봉뜨락 업무로그 — 단톡방 대화 자동 분류 → 구글 시트

단톡방 대화나 현장 메모를 붙여넣으면 Gemini가 **[결정] / [할일] / [공유] / [아이디어]** 로
나눠 담당자·마감일·우선순위까지 뽑아주고, 확인한 것만 구글 시트에 행으로 쌓는 모바일 웹 도구입니다.

```
붙여넣기 → [AI로 자동 분류] → 카드에서 담당자·마감일 확인/수정 → [시트 전송] → 시트에 행 추가
```

**Google Apps Script 웹앱** 한 개로 끝납니다. 서버도, OAuth 설정도, 배포 파이프라인도 없습니다.
구글 계정 하나와 Gemini API 키 하나면 됩니다. 비용은 Gemini 호출분(사실상 0원 수준)뿐입니다.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버. Gemini 호출, 응답 정규화, 시트 적재, 접근 코드 검사 |
| `index.html` | 화면. 붙여넣기 → 분류 결과 카드 → 전송 (외부 CDN 없음) |
| `appsscript.json` | 매니페스트 (권한·시간대·웹앱 설정) |
| `test_code.js` | 정규화 로직 테스트 — `node test_code.js` |
| `preview.mjs` | 배포 없이 화면만 확인 — `node preview.mjs` |

---

## 1. 준비물

1. **구글 계정** — 시트를 소유할 계정. 대표 계정 하나로 만들고 셋이 공유하는 편이 낫습니다.
2. **Gemini API 키** — [aistudio.google.com](https://aistudio.google.com/apikey) → `Get API key`.
3. **빈 구글 스프레드시트** 하나. 주소창의 `/d/` 와 `/edit` 사이 문자열이 **시트 ID** 입니다.
   ```
   https://docs.google.com/spreadsheets/d/1AbCd...XyZ/edit
                                          └──── 이 부분 ────┘
   ```
   시트 탭과 헤더(A~H)는 첫 저장 때 `업무로그` 시트로 자동 생성되므로 미리 만들 필요 없습니다.

> ⚠ **무료 등급 주의**: Gemini API 무료 등급은 입력 내용이 모델 개선에 쓰일 수 있습니다.
> 견적·계약·인사 같은 내부 정보를 넣을 것이므로, 결제를 연결한 유료 등급 키 사용을 권합니다.

## 2. 설치 (웹 에디터, 5분)

1. [script.google.com](https://script.google.com) → **새 프로젝트**. 이름은 `봉뜨락 업무로그`.
2. 기본으로 있는 `Code.gs` 내용을 지우고, 이 폴더의 **`Code.gs` 전체**를 붙여넣습니다.
3. 왼쪽 `파일 +` → **HTML** → 이름을 정확히 **`index`** 로 만들고, **`index.html` 전체**를 붙여넣습니다.
   (파일명이 `index` 가 아니면 화면이 뜨지 않습니다.)
4. ⚙ **프로젝트 설정** → `"appsscript.json" 매니페스트 파일 표시` 체크 → 편집기에서 이 폴더의
   `appsscript.json` 내용으로 교체합니다.

<details>
<summary>개발자용: clasp 로 올리기</summary>

```bash
npm i -g @google/clasp
clasp login
clasp create --type webapp --title "봉뜨락 업무로그" --rootDir .
clasp push          # Code.gs / index.html / appsscript.json 이 그대로 올라갑니다
```
`.clasp.json` 은 `.gitignore` 에 있습니다(스크립트 ID가 들어가므로).
</details>

## 3. 설정값 입력

⚙ **프로젝트 설정 → 스크립트 속성 → 속성 추가** 에서 아래를 넣습니다.
API 키를 코드에 직접 쓰지 마세요. 여기 넣으면 저장소에도 화면에도 노출되지 않습니다.

| 속성 이름 | 필수 | 값 | 설명 |
|---|:--:|---|---|
| `GEMINI_API_KEY` | ✅ | `AIza...` | AI Studio 에서 발급한 키 |
| `SHEET_ID` | ✅ | `1AbCd...XyZ` | 적재할 스프레드시트 ID |
| `GEMINI_MODEL` | | `gemini-3.7-flash` | 비우면 이 값. 아래 "모델 선택" 참고 |
| `GEMINI_THINKING_LEVEL` | | `low` | Gemini 3.x 의 사고 강도(`low`/`medium`/`high`). 비우면 `low`(속도 우선). `off` 면 옵션 자체를 안 보냄 |
| `GEMINI_THINKING_BUDGET` | | `0` | **2.5 계열 모델을 쓸 때만.** 지정하면 위 레벨 대신 이 값을 보냄 |
| `ACCESS_CODE` | | `bongttorak26` | 설정하면 화면에서 이 코드를 입력해야 동작. 아래 "접근 제한" 참고 |

### 모델 선택

기본값은 **`gemini-3.7-flash`** 입니다 (2026년 9월 기준). 짧은 입력을 대량으로 빠르게 처리하는
용도에 권장되는 모델이라, 단톡방 몇 줄을 분류하는 이 도구에 맞습니다.

| 모델 ID | 언제 쓰나 | 참고 (2026-09) |
|---|---|---|
| `gemini-3.7-flash` **(기본)** | 지연시간이 중요한 분류·추출 | 입력 $0.75 / 출력 $3.75 per 1M |
| `gemini-3.5-flash-lite` | 더 싸고 더 빠르게 | 입력 $0.30 / 출력 $2.50 per 1M |
| `gemini-3.8-flash` | 대화가 길고 복잡해 분류 품질이 아쉬울 때 | 3.7과 동가격이나 사고 토큰을 더 씀 |

> ⚠ **`gemini-2.5-flash` 는 쓰지 마세요.** 폐기(deprecated) 상태이며 **2026년 10월 16일 종료**
> 예정입니다(2.5 Pro·Flash-Lite 동일). 2.5 계열을 굳이 써야 한다면 `GEMINI_THINKING_BUDGET`
> 속성을 함께 넣어야 합니다 — 3.x 는 `thinkingLevel`, 2.5 는 `thinkingBudget` 으로 파라미터가
> 다르고 둘을 같이 보내면 400 오류가 납니다. 코드는 하나만 보내고, 그래도 모델이 거부하면
> 그 옵션만 빼고 자동 재시도합니다.
>
> 가격·모델 목록은 바뀝니다. 배포 전 [ai.google.dev/gemini-api/docs/models](https://ai.google.dev/gemini-api/docs/models)
> 와 [폐기 일정](https://ai.google.dev/gemini-api/docs/deprecations)을 한 번 확인하세요.
> 존재하지 않는 ID를 넣으면 화면에 `모델 ... 을(를) 찾을 수 없습니다` 라고 그대로 나옵니다.

## 4. 배포

1. 오른쪽 위 **배포 → 새 배포 → 유형 `웹 앱`**
2. 설정
   - **실행 계정**: `나` — 세 명이 각자 구글 로그인을 하지 않아도 시트에 쓸 수 있습니다.
   - **액세스 권한**: `모든 사용자` (링크를 아는 사람) 또는 `Google 계정이 있는 모든 사용자`
3. **배포** → 권한 승인 (`고급` → `프로젝트로 이동` → 허용). 시트 쓰기와 외부 호출 권한입니다.
4. 나오는 **웹앱 URL** 이 최종 결과물입니다. 성현·지연·주성 각자 휴대폰으로 열고
   **홈 화면에 추가**(사파리: 공유 → 홈 화면에 추가 / 크롬: ⋮ → 홈 화면에 추가)하면 앱처럼 씁니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전 `새 버전` → 배포** 를 해야 URL에 반영됩니다.
> (URL은 그대로 유지됩니다.)

### 접근 제한

`액세스 권한: 모든 사용자` 로 배포하면 **URL을 아는 사람은 누구나** 시트에 쓸 수 있습니다.
`ACCESS_CODE` 속성을 설정하면 화면에 코드 입력칸이 생기고, 코드가 맞아야 분류·저장이 됩니다.
셋이 쓰는 도구라면 이 정도가 적당합니다. 더 조이려면 배포 시 액세스를 `Google 계정이 있는
모든 사용자` 로 두고, 코드까지 함께 쓰면 됩니다.

## 5. 시트 적재 포맷

첫 저장 때 `업무로그` 시트가 헤더·고정행·상태 드롭다운까지 갖춰져 자동 생성됩니다.

| A 타임스탬프 | B 분류 | C 핵심 요약 | D 담당자 | E 마감일 | F 우선순위 | G 상태 | H 원문 맥락 |
|---|---|---|---|---|---|---|---|
| 2026-09-14 15:30 | [결정] | 매표소 포스기 렌탈 vs 구매 확정 필요 | 성현 | 2026-09-15 | HIGH | 대기 | 월 30만 vs 일시불 150만 견적 비교 건 |
| 2026-09-14 15:30 | [할일] | 짚코스터 하네스 일일점검 체크리스트 초안 작성 | 주성 | 2026-10-05 | HIGH | 대기 | 제조사 매뉴얼 기반 작성 요청 |
| 2026-09-14 15:30 | [공유] | 군청 관광과 주무관 통화 완료 (인허가 실사 일정) | 성현 | 미정 | MEDIUM | 완료 | 금요일 오후 현장 방문 예정 |
| 2026-09-14 15:30 | [아이디어] | 동절기 눈썰매 연계 패키지 구성 | 지연 | 미정 | LOW | 검토 | 11월 오픈 이후 12월 회의 안건으로 이첩 |

- 시간대는 `Asia/Seoul` 고정입니다.
- 담당자는 `성현 / 지연 / 주성 / 공통 / 미지정` 중 하나로만 들어갑니다.
- 마감일은 `YYYY-MM-DD` 아니면 `미정` 입니다. 모델이 애매한 날짜를 주면 `미정` 으로 떨어집니다.
- 상태 기본값: `[결정]·[할일] → 대기`, `[공유] → 완료`, `[아이디어] → 검토`. 시트에서 드롭다운으로 바꿉니다.
- 타임스탬프·마감일 열은 텍스트 서식으로 고정해 두어 `미정` 과 날짜가 섞여도 서식이 깨지지 않습니다.

## 6. 쓰는 법

1. 단톡방에서 대화를 길게 눌러 **복사** → 도구 열고 붙여넣기 (한 번에 12,000자까지).
2. **[AI로 자동 분류]** — 결과가 카드로 뜹니다.
3. 카드에서 **담당자·마감일·분류를 눈으로 확인**하고 틀린 것만 고칩니다. 필요 없는 카드는 `제외`.
4. 카드별 **[승인 및 시트 전송]** 또는 하단 **[전체 시트 전송]**.
5. `Google 시트에 N건의 업무가 성공적으로 등록되었습니다.` 토스트와 시트 링크가 뜹니다.

- 입력창 내용은 브라우저에 임시 저장되므로, 쓰다가 전화가 와도 날아가지 않습니다.
- 음성 입력(🎤)은 지원 브라우저(안드로이드 크롬 등)에서만 버튼이 보입니다. 현장에서 손이 젖었을 때용.
- 분류 결과가 마음에 안 들면 그냥 다시 누르면 됩니다. **시트에는 전송을 눌러야만 들어갑니다.**

### 설계상 일부러 이렇게 한 것

- **분류와 저장이 두 단계**입니다. 모델이 담당자나 마감일을 잘못 짚는 경우가 분명히 있고,
  한 번 잘못 쌓인 원장은 나중에 아무도 믿지 않게 됩니다. 사람이 5초 훑고 보내는 값이 그보다 큽니다.
- **모델 응답을 그대로 시트에 넣지 않습니다.** 분류·담당자·우선순위는 허용된 값으로만 강제하고,
  날짜는 형식 검사를 통과한 것만, 나머지는 `미정` 으로 떨어뜨립니다. 화면에서 온 값도 서버에서 다시 검사합니다.
- **한 번에 최대 50건**입니다. 사고로 수백 행이 꽂히는 상황을 막습니다.
- **동시 저장 잠금**이 걸려 있습니다. 셋이 동시에 눌러도 행이 겹쳐 쓰이지 않습니다.

화면(`index.html`)을 고칠 때는 이걸로 먼저 보고, 서버 로직(`Code.gs`)의 정규화를 고칠 때는
`test_code.js` 에 케이스를 추가하세요.

## 8. 문제 해결

| 증상 | 원인과 조치 |
|---|---|
| `GEMINI_API_KEY 스크립트 속성이 비어 있습니다` | 3단계 속성 입력 누락. 속성 이름 오타(앞뒤 공백 포함) 확인 |
| `SHEET_ID 로 시트를 열지 못했습니다` | 시트 ID 오타이거나, 배포 실행 계정에 그 시트 편집 권한이 없음 |
| `모델 ... 을(를) 찾을 수 없습니다` | `GEMINI_MODEL` 값 확인. 비워두면 `gemini-3.7-flash` 를 씁니다. 폐기된 모델(2.5 계열)을 넣어도 이 오류가 납니다 |
| `요청이 몰렸습니다` | Gemini 무료 등급 분당 한도. 잠시 후 재시도(코드가 2회까지 자동 재시도합니다) |
| 화면이 안 뜨고 오류 페이지 | HTML 파일 이름이 `index` 인지 확인 |
| 코드를 고쳤는데 그대로 | 배포 관리에서 **새 버전**으로 다시 배포해야 반영됩니다 |
| `내용이 너무 길어 결과가 잘렸습니다` | 대화를 반으로 나눠서 두 번 넣으세요 |
| 분류가 계속 엉뚱함 | `Code.gs` 의 `SYSTEM_PROMPT` 규칙에 실제 사례를 한 줄 추가하는 게 가장 빠릅니다 |

## 9. 남은 것 / 다음 단계

- **중복 방지 없음**: 같은 대화를 두 번 붙여넣으면 두 번 쌓입니다. 필요해지면 요약 해시로 거르면 됩니다.
- **상태 관리는 시트에서**: 완료 처리는 시트 G열 드롭다운으로 합니다. 도구에서 되돌려 고치는 기능은 없습니다.
- **알림 없음**: 마감일 임박 알림이 필요하면 Apps Script 시간 기반 트리거로 시트를 훑어
  카카오 알림 대신 메일을 보내는 함수를 붙이는 게 가장 저렴합니다.
- **호출 방식**: `v1beta` 의 `generateContent` 를 씁니다. 2026년 6월부터 구글은 신규 프로젝트에
  **Interactions API** 를 권하지만, `generateContent` 는 종료 일정 없이 계속 지원됩니다.
  이 도구는 요청 한 번에 끝나는 단순 분류라 서버측 상태 관리가 필요 없어 그대로 두었습니다.
  나중에 대화 맥락을 이어가는 기능이 필요해지면 그때 옮기면 됩니다.
- 모델은 반년 단위로 교체됩니다. `GEMINI_MODEL` 속성 하나만 바꾸면 되도록 코드에 하드코딩하지
  않았으니, 폐기 안내 메일이 오면 속성만 갈아끼우세요.
- 이 저장소의 `agents/` 도구들과는 독립적입니다(그쪽은 파이썬 + Claude API, 이쪽은 Apps Script + Gemini).
  나중에 시트를 `agents/daily_report.py` 의 입력으로 쓰면 일일 리포트에 미완료 할일을 붙일 수 있습니다.
