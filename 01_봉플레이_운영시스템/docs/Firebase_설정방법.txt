봉뜨락 V3 멀티플레이 설정 방법
================================

포함 파일
- metaverse_V3.html : 멀티플레이 클라이언트
- firebase-config.js : Firebase 연결 정보
- database.rules.json : Realtime Database 보안 규칙
- firebase.json : Firebase Hosting 배포 설정

1. Firebase 프로젝트 생성
- Firebase Console에서 새 프로젝트를 만듭니다.
- 프로젝트 설정 > 내 앱 > 웹 앱 추가를 선택합니다.
- 표시되는 firebaseConfig 값을 firebase-config.js에 붙여 넣습니다.

2. 익명 로그인 활성화
- Firebase Console > Authentication > 시작하기
- Sign-in method > 익명(Anonymous)을 활성화합니다.

3. Realtime Database 생성
- Build > Realtime Database > 데이터베이스 만들기
- 위치를 선택하고 잠금 모드로 생성합니다.
- 규칙 탭에 database.rules.json의 내용을 붙여 넣고 게시합니다.

4. 배포
방법 A — Firebase CLI
- Node.js 설치
- 명령 프롬프트에서 이 폴더로 이동
- npm install -g firebase-tools
- firebase login
- firebase use --add
- firebase deploy
- 배 후 표시되는 Hosting 주소에서 metaverse_V3.html을 엽니다.

방법 B — 이미 사용 중인 Netlify/Render 정적 사이트
- metaverse_V3.html과 firebase-config.js를 같은 폴더에 둡니다.
- 해당 폴더 전체를 배포합니다.
- 단, Firebase Console > Authentication > Settings > 승인된 도메인에 배포 도메인을 추가합니다.
- Realtime Database 규칙은 별도로 database.rules.json 내용으로 설정합니다.

5. 세 사람 접속
- 동일한 배포 주소를 세 사람에게 공유합니다.
- 각자 다른 닉네임과 색상을 골라 입장합니다.
- 같은 화면/실내 공간에 있을 때 서로의 캐릭터와 말풍선이 표시됩니다.
- 관제 패널에서 현재 접속자와 위치를 볼 수 있습니다.

중요
- file:/// 로 직접 여는 대신 HTTPS 배포 주소로 접속하는 것을 권장합니다.
- firebase-config.js의 API 키는 웹 앱 식별 정보이므로 클라이언트에 포함되는 것이 정상입니다.
- 실제 보호 장치는 Authentication과 Realtime Database 보안 규칙입니다.
- firebase-config.js의 ROOM_ID가 같은 사용자끼리 같은 방에 연결됩니다.
