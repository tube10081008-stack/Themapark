## 0. 사용 원칙 (법적)

- 원본 저장소에 **라이선스 파일이 없음** (GitHub API license 404) → 저작권자가 모든 권리를 보유한 상태.
- 따라서 **코드·데이터 파일(voxel_heights.lua 등)은 복사하지 않는다.** 기법(아이디어)과 수치만 참고하고, 봉플레이 코드는 처음부터 새로 작성한다.
- 포켓몬 그래픽·지도는 일절 사용하지 않는다. 타일 그림은 봉뜨락 시설을 기준으로 **직접 그린다**.

## 1. 결론: "섬세한 질감"은 어디서 오나

조사 결과, 절차적 노이즈나 고해상도 텍스처가 아니다. 네 가지의 조합이다.

| # | 요소 | 핵심 |
|---|---|---|
| 1 | **원본 도트 그림을 입체 면에 그대로 입힘** | 8×8 타일 그림을 윗면과 옆면에 1:1로 매핑. 옆면은 늘이지 않고 8px 띠로 반복, 높이가 모자라면 잘라냄. `nearest` 필터 |
| 2 | **꼭짓점 AO를 미리 계산** | 모서리·구석·바닥 접촉부를 꼭짓점 색으로 어둡게 → 블록 사이 "주름"이 생겨 입체감이 생김 |
| 3 | **면 방향별 명암** | 남쪽 면 1.0 / 윗면 0.85 / 그 외 옆면 더 어둡게 (0.55~1.0 범위) |
| 4 | **선명한 그림자 + 미니어처 후처리** | 남동쪽 45° 해에서 내리는 딱딱한 그림자, 틸트시프트 블러, 채도 강화, 지면 곡률 |

## 2. 기법별 상세 (수치 포함)

### 2-1. 타일 → 형태 (TileShape)
- 픽셀 색으로 높이를 추정하지 **않는다**. 타일마다 **형태 분류(class)** 를 주고, 분류별 고정 높이를 쓴다.
- 우선순위: ① 수작업 지정 → ② 칸의 통행 가능 여부(걸을 수 있으면 바닥, 물이면 물) → ③ 나머지는 벽
- 분류별 높이 예 (단위: 월드 픽셀, 타일 = 8px):
  - 바닥 0 / 물 −2 / 벽 16 / 책상 24 / 지붕 28
- 충돌 판정은 16×16 칸의 **왼쪽 아래 타일 하나만** 본다 → 장식 타일이 엉뚱하게 솟지 않음
- 렌더 방식: 평면 사각형 / 세운 벽 / 윗면 있는 상자 / 원기둥 등 분류가 결정

### 2-2. 메시 생성·명암·AO (ChunkMesher)
- 이웃 타일이 **더 낮을 때만** 옆면 생성 (숨은 면 자동 제거)
- 구조물 분류: 평면 / 윗면 그림 있는 상자 / 기둥 / 소품
- 면 명암: 남쪽 옆면 1.0, 윗면 0.85, 박공지붕 0.95, 그 외 옆면은 같은 그림을 어둡게
- AO (꼭짓점별, 주변 높이 기준):
  - 세기 2.4 / 이웃 1개당 0.216 (최대 3개) / 안쪽 모서리 0.664 / 모서리+주름 0.441
  - 소품-바닥 접촉 0.288, 6px 높이에 걸쳐 옅어짐 / 최저 밝기 0.25
  - 대각선만 막힌 경우는 더하지 않음 (과도한 어둠 방지)
- 아틀라스: 128×48 (16열×6행), UV를 **0.02 텍셀 안쪽으로** 줄여 이웃 타일 번짐 방지
- 색 변화는 **아틀라스 그림 + 꼭짓점 음영뿐**. 노이즈·점묘 없음

### 2-3. 그림자 (ShadowMap)
- 해 방향 고정: 높이 y 인 점의 그림자가 (−0.85y, −0.55y) 로 떨어짐 → 남동쪽 약 45°
  - 정북 그림자는 캐릭터 밑에 숨으므로 일부러 서쪽으로 비틈
- 해상도 1024 / 1536 / 2048 중 **텍셀당 0.45 월드픽셀**을 만족하는 최소값을 자동 선택
- 바이어스 1.0 월드픽셀, **nearest 필터 (부드럽게 하지 않음)** → 복셀 느낌의 딱딱한 그림자
- 최종 그림자 어둡기 0.40, 가장자리는 2×2 필터

### 2-4. 캐릭터 (SpriteBillboards)
- 16×16 도트 캐릭터를 **평면 한 장**으로 세움
- 항상 남쪽을 보고, **발을 축으로 카메라 기울기만큼 뒤로 젖힘** → 어느 각도에서도 정면으로 읽힘
- 걷기·방향 전환은 좌우 반전으로 처리 (메시 추가 없음)
- 같은 평면이 본체·그림자·가림 실루엣에 모두 쓰여 어긋남이 없음

### 2-5. 틸트시프트 (TiltShift)
- 화면 세로 가운데(0.5)가 초점. 위아래로 갈수록 흐려짐
- 9탭 가우시안 (가중치 약 0.227 / 0.195 / 0.122 / 0.054 / 0.016), **가로→세로 2패스**
- 단계별 선명 구간 반높이: 0.14 / 0.10 / 0.07
- 마지막 패스에서 **채도 강화** → "미니어처 사진" 느낌

### 2-6. 지면 곡률 (WorldCurve)
- 꼭짓점 셰이더 한 줄: `y -= k × (카메라 초점까지 수평거리)²`
- k = 세기 ÷ 화면높이(월드), 세기 0 / 0.05 / 0.10 / 0.18
- **y 축만** 내리므로 건물이 기울지 않고, 픽셀 재샘플링이 없어 도트가 선명
- 곡률은 그림자 계산 뒤에 적용

### 2-7. 카메라·합성 (Voxel3D)
- 초점거리를 고정해 수직 시점과 기울인 시점의 화면 구도가 같음
- 기울기 0°(수직)~50°, 설정값 15 / 35 / 50 / 75
- 합성: `색 = 아틀라스 × 면·AO 음영 × 햇빛(그림자)`, 알파 0.5 미만은 버림
- AA 는 슈퍼샘플링 2× / 4×

### 2-8. 건물 (sprite_to_voxel_methodology)
- 2D 건물 그림을 가로 띠로 나눠 판별: 평평한 지붕 / 경사 지붕 / 벽(창·문) / 처마
- 벽은 뒤로 일정 깊이 돌출, 창·문은 앞 복셀을 지워 **움푹하게**, 처마는 앞뒤 ±2 돌출
- 경사 지붕: 그림이 좁아지는 비율 = 경사
- 지붕 돌출 약 4복셀, 윤곽선은 검정-회색-검정 층

## 3. 봉플레이(웹) 적용 설계 — Three.js 대응표

| 원본 기법 | 웹 구현 |
|---|---|
| 8px 도트 아틀라스, nearest | 봉뜨락 전용 16px 아틀라스 직접 제작, `NearestFilter`, 밉맵 끔, UV 0.02 텍셀 인셋 |
| 분류별 고정 높이 | 타일 분류표(`ground/deck/net/wall/roof/rail/water/tree`) + 높이 상수 |
| 이웃이 낮을 때만 옆면, 8px 띠 반복 | 자체 메셔: 옆면 UV 를 높이만큼 반복·잘라내기, `BufferGeometry` 한 덩어리 |
| 면 명암 + 꼭짓점 AO | 꼭짓점 색(`vertexColors`)에 면 명암 × AO 곱해서 굽기 (위 상수로 시작해 조정) |
| 남동 45° 딱딱한 그림자 | `DirectionalLight` + `BasicShadowMap`(부드럽게 안 함), 해상도 1024~2048 자동, 그림자 어둡기 0.4 |
| 발 축 기울임 스프라이트 | 평면 메시를 발 기준으로 카메라 pitch 만큼 회전 |
| 틸트시프트 + 채도 | `EffectComposer` 사용자 패스 2개(가로·세로 9탭) + 채도 |
| 지면 곡률 | 머티리얼 `onBeforeCompile` 로 꼭짓점 셰이더에 한 줄 추가 |
| 슈퍼샘플 AA | `renderer.setPixelRatio(devicePixelRatio × 배율)`, 저사양은 끔 |
| 물 흐름 | 물 타일 텍스처 가로 이동(hshift) |

## 4. 봉뜨락 타일 목록 (직접 그릴 것)

바닥: 잔디 / 흙길 / 데크 / 고무매트 / 주차장 / 물(개울)
시설: 실내놀이동 벽·지붕 / 네트어드벤처(그물 반투명) / 짚코스터 레일·기둥 / 트램펄린 / 썰매 슬로프 / 카페 / 매표소 / 화장실
자연: 소나무 / 사과나무 / 바위 / 꽃
사람: 방문객·직원·안전요원 도트 캐릭터 (16×16, 4방향 × 걷기 2프레임)

## 5. 단계

1. 시험판: 아틀라스 1장 + 봉뜨락 단순 지도 + 메셔 + 명암/AO + 그림자 + 캐릭터 1명
2. 후처리(틸트시프트·곡률·채도) 추가, 저사양 태블릿 성능 확인
3. 기존 metaverse.html 의 지도·멀티플레이를 새 렌더러로 교체
4. 운영 데이터 연결 (짚코스터 운행 여부, 혼잡도)
