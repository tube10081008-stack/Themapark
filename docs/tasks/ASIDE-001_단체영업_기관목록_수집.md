# ASIDE-001 — 지오: 봉화·안동·영주 교육·보육기관 공개 목록 수집

배정: Ben · 담당: 지오 · 2026-09-29. GEO-001 검증 결과를 PR로 인계한 뒤 착수한다. 기존 GEO-001의 코드 감사와 다른 업무다.

## 목적과 범위

평일 단체 영업을 검토할 기관 목록을 만든다. 대상은 봉화군·안동시·영주시의 유치원, 어린이집, 초등학교다. 공공 정보공개·공시 포털, 교육청·지자체의 공식 목록 등 공개된 공식 자료만 읽는다. 검색 결과 요약이나 민간 디렉터리를 확인된 기관 데이터로 쓰지 않는다.

기관명, 유형, 공식 식별코드(있으면), 시군, 도로명 주소, 공개 기관 대표번호, 공식 홈페이지, 운영 상태, 원아/학생 수와 기준연도, 출처 URL·확인일을 수집한다. 개인 이름·직통 개인번호·이메일·아동 단위 정보는 수집하지 않는다. 기관에 전화·메일·문의·메시지를 보내지 않는다.

## 방법

1. 시군 3개 × 기관유형 3개의 9칸을 조사표로 만든다. 각 칸의 공식 출처와 기준일을 먼저 확인한다.
2. 공식 목록의 다운로드 기능이 있으면 활용하고, 없으면 페이지를 순서대로 확인한다. 페이지 수/필터/조회 총수를 기록하여 누락을 점검한다. 로그인이나 비공개 접근이 필요한 항목은 공개 대체 자료를 찾거나 미확인으로 남긴다.
3. 기관 코드가 있으면 코드로, 없으면 정규화한 기관명+주소+유형으로 중복을 판별한다. 초등학교와 병설유치원은 주소가 같아도 다른 기관유형으로 남기고 관계를 메모한다.
4. 원아·학생 수가 없거나 오래됐으면 빈 값과 기준연도/사유를 남긴다. 0으로 대체하거나 정원을 실제 재원 수로 쓰지 않는다. 폐원·휴원·통폐합 상태도 출처 기준으로 기록한다.
5. 9칸 각각 출처 총수와 수집 수를 비교한다. 분류 차이·누락·접근 제한을 설명한다. 전수 확인하지 못했으면 전체 목록이라고 단정하지 않는다.
6. 거리 산정·우선순위·영업 문구는 이번 범위에서 제외한다. 이후 클로이가 도로명 주소를 기준으로 거리 측정 방법과 출발지를 명시해 평가한다.

## 산출물과 저장 위치

- `ASIDE-001_institutions.csv`: UTF-8 BOM, 1행 1기관. 권장 열은 `institution_id, institution_name, institution_type, municipality, road_address, public_main_phone, official_website, operation_status, enrolment_count, enrolment_year, source_url, checked_at, notes`.
- 서로 다른 필드의 출처가 다르면 별도 `ASIDE-001_sources.csv`에 기관 식별자·필드·URL·자료 기준일을 기록한다. 전화번호는 선행 0을 보존한다. CSV 셀을 수식으로 해석하게 만드는 입력은 텍스트로 안전하게 다룬다.
- 대표에게 전달할 요약에는 지역/유형별 수, 중복 처리, 결측률, 기준연도 분포, 미확인 칸과 사유를 적는다.
- **CSV와 원시 다운로드는 Git 저장소 밖의 대표 전달 폴더에 저장한다. 커밋하거나 GitHub PR/이슈에 첨부하지 않는다.** 저장 위치는 지오 환경에서 명확히 보고한다.
- 저장소에는 수집 방법·수량·제약만 담은 `docs/research/ASIDE-001_수집방법과_커버리지.md`와 작업표 해당 행을 별도 `aside/ASIDE-001-institution-directory` 브랜치에서 PR로 제출할 수 있다. 기관별 데이터는 이 문서에도 복제하지 않는다.
