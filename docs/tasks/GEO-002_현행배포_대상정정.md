# GEO-002 현행 배포 식별 및 읽기 검증

2026-09-30 벤. 대표가 직접 정정한 운영 대상이다. 기존 GEO-001 후속의 대상 지시보다 이 문서를 우선한다.

## 확정된 대상과 근거 수준

- 실제 운영: https://bongplay.netlify.app/
- 실제 사용 중인 아카이브: https://bongplaychat.netlify.app/archive.html
- https://bongplaychat2.netlify.app/ 는 과거 MVP이며 최신화되지 않았다. 현행 운영 검증 대상에서 제외한다.
- 두 현행 서비스에 최신 ZIP을 배포했다는 것은 대표 확인 사항이다. ZIP과 Git SHA 일치는 아직 별도 검증 전이다.
- 대표는 지오가 원래 Netlify 운영 계정의 로그인된 화면에 접근할 수 있도록 준비했다. 로그인 식별자는 저장소에 기록하지 않는다. 지오는 프로젝트의 실제 도메인으로 대상을 확인한다.

## 지오 우선 실행

ASIDE-001 수집보다 이번 대상 정정 검증을 우선한다. 이미 수집한 자료는 보존한다. 최신 origin/master에서 aside/GEO-002-live-deployment-audit 브랜치를 만들고 본 작업 행에 기준 SHA를 기록한다.

1. 대표가 열어 둔 Netlify 계정에서 두 도메인에 해당하는 프로젝트를 찾는다. 다른 팀이나 chat2로 대체하지 않는다. 화면을 찾지 못하면 대상 미확인으로 보고한다.
2. 각 프로젝트의 현재 published 배포 ID, 화면상 배포 시각과 시간대, 배포 방식, 도메인을 읽기 확인한다. ZIP/산출물의 버전 표식과 Git 커밋 근거가 있으면 기록하고, 없으면 연결 미확인으로 남긴다. 최신 ZIP이라는 말만으로 master와 동일하다고 단정하지 않는다.
3. 숫자 없는 실제 서비스에서 접근 게이트·아카이브 분류·실데이터/샘플 표시를 확인한다. 업무로그 및 시트 진단은 현행 화면에 실제 연결이 있을 때만 읽기 확인한다. 로그인된 세션과 별도 쿠키 없는 세션을 구분하고, 후자가 불가능하면 미검증으로 기록한다. 개인 기록 본문·파일명·시트 전체 ID·인증값을 수집하거나 보고서에 복사하지 않는다.
4. GEO-001의 접근 위험, 48행 원장, 73개 아카이브와 분류 0건, 크레딧/배포 중단은 **구 MVP에서의 관찰**이다. 현행 서비스에서 재확인하기 전 현행 결함/배포 제약으로 인용하지 않는다. 원본 감사는 삭제하지 않고 적용 범위를 정정한다. 저장소 코드상 초안/중복 위험은 코드 분석으로 남기되 현행 배포에서 재현됐다고 하지 않는다.
5. docs/qa/GEO-002_현행배포_검증.md에 도메인별 결과·증거 수준·미실행·후속 권고를 적어 master 대상 문서 PR을 제출한다. GEO-001 감사 머리말에 본 보고서 링크를 추가하고 작업표의 본인 행만 갱신한다.

운영 분류/저장/서식 적용/시트 쓰기/환경변수 변경/재배포/구매는 수행하지 않는다. API 직접 접근 대신 현재 사용 가능한 브라우저 화면으로 확인한다. 분리 테스트 환경은 존재 여부만 확인한다. 확인 후 ASIDE-001 기관 목록 수집을 재개하고 신규 블로그 게시는 하지 않는다.
