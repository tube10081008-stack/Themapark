# BEN-011 전체 작업 병행 실행

2026-10-01 벤. 대표가 전체 작업 추진을 승인했다. BEN-008/010의 확정 정책을 유지하며 이 문서가 다음 실행 순서를 지정한다. 기존 작업을 버리거나 반복하지 말고 원격 최신 상태를 확인한다.

## 고정 원칙

- 업무로그·아카이브·Drive 원본은 직원 전용, 삭제는 관리자만. 내부 아카이브로 통일하고 ZIP 수동 배포를 유지한다.
- 버스 지원은 자체 판촉비 계획이며 금액·최소 인원 미정. 군 지원 확정 안내 금지.
- 운영 권한/스키마/배포 변경은 영향·대상·선행 조건·복구 방법과 검증 결과를 갖춘 배포 검토를 거친다. 지금은 준비·코드·합성 테스트 단계다. 사용자 계정/원본 자료를 임의로 변경하지 않는다.
- 담당자는 완료 시 최종 SHA/원격 일치/PR/검증 및 미실행/결정 요청을 보고한다. 대표 결정 질문은 벤이 취합한다. 비밀값·실제 기록·개인 식별자를 커밋하지 않는다.
- 같은 폴더의 구현 소유권은 아래 배정을 따른다. 지오는 문서/읽기 확인만 담당한다. ANT-001과 후속 ANT-003의 중복 파일 구현은 동시에 수행하지 않는다.

## 아난티 — 운영 마무리와 직원 접근 통제·아카이브 통합

### 1. ANT-001 / 기존 PR #11 우선

BEN-009의 실제 흐름 3종 및 BEN-010/PR 최신 리뷰를 완료한다. d94411d 진단 스크립트는 전체 완료 증거가 아니다. 테스트 실행 인프라가 막히면 제한된 시간 내 진단을 제출하고 무한 반복하지 않는다. 빈 페이지 연결→종료 smoke, 실제 안전점검→매표, 입장→취소→퇴장/타 단말, 마감 A/B 전환을 단계별로 진행한다. 진단 스크린샷에도 timeout을 적용한다.

폐지된 7,000원 신규 판매 버튼·연결 계산/주문 경로 차단, 미확정 군 버스비 지원 문구 정정도 포함한다. 과거 원장과 짚코스터 단품 7,000원은 보존한다. 안전/취소/마감 검증 실패는 승인되지 않는다.

### 2. ANT-003a / 설계는 지금 착수 가능

최신 master에서 `antigravity/ANT-003a-staff-archive-design`. `docs/design/ANT-003_직원접근_내부아카이브.md` 및 본인 작업표 행만 변경하는 문서 PR.

- GEO-003의 기능표/자료 공급원/관찰 제약을 입력으로 사용한다. 화면 인증 외에도 업무로그 API, GAS 목록·업로드·폴더·삭제, 원본 Drive·썸네일/다운로드, 캐시·로그아웃까지 보호 경계를 정의한다.
- 직원/관리자 신원을 서버에서 검증할 방법을 제시한다. 브라우저에 공용 암호·서버 비밀키를 넣거나 클라이언트 플래그만 신뢰하지 않는다. 기존 인증 재사용 가능성은 실제 서버 계약을 검토하고 결정한다.
- 원본 파일 직원 제한 후 썸네일/다운로드를 제공하는 방법, 구 봉챗 경로의 우회 접근 차단, 기존 11분류 보존/중복 분류 정리, 업로드/검색/미리보기 등 기능 유지안을 명시한다.
- 미인증/일반직원/관리자 권한 행렬, 실패/만료/철회/로그아웃/캐시 테스트, 필요한 서버·설정 변경과 ZIP/DB/GAS/Drive 적용 순서, 기존 공유 링크 영향 및 복구 절차를 적는다.
- 관리자 지정 방식·영구삭제/휴지통 정책처럼 미확정 운영 선택은 벤에게 질문한다. 기존 직원전용/관리자 삭제 결정을 재질문하지 않는다.

### 3. ANT-003b / 설계 검토와 #11 통합 후 구현

벤의 설계 검토를 받은 뒤 최신 master에서 `antigravity/ANT-003b-staff-archive`. 범위는 01/04와 실제 참조되는 GAS 소스, 테스트, 설정 템플릿, 제안 DB 변경, 관련 문서다. 02/05는 수정하지 않는다. 공용 assets·인증 관련 구현은 아난티 단독 소유다.

테스트 더블은 네트워크/저장 경계에 두고 실제 앱 동작을 시험한다. 미인증 요청은 목록·파일·업로드/삭제 모두 거부되고 일반 직원은 삭제 불가, 관리자만 허용되어야 한다. 목록 11분류/자료 연결을 보존하며 자료 복사·재적재 없이 전환한다. 새 기능과 정책을 한 번에 운영 적용하지 말고 검토 가능한 단계로 PR을 분리한다.

## 벤 — BEN-012 버스비 지원안 및 통합

대표가 정할 월 판촉비 한도와 단체 추가비용을 확인한다. 미정이면 가정을 명시한 인원·인당 지원·매출비율 상한·예약별 상한 시나리오로 비교한다. 미확정 군 재원·실제 버스 견적을 사실처럼 넣지 않는다. 무료 인솔자/할인 중복/취소·환불/예산 소진 조건을 포함해 대표에게 최종안을 제시한다. 분석은 운영 개발과 병행 가능하다.

작업별 PR을 독립 검토하고 공동 작업표 충돌은 벤이 조정한다. 운영 변경은 하나의 완료 보고로 승인하지 않고 산출물·영향·검증·복구를 갖춘 별도 배포 단계로 관리한다. ANT-002 브랜드와 004c/d 에이전트 본체는 이번 운영 작업 범위 밖이다.
