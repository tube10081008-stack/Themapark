## 목표와 현황

직원 인증 전 업무로그·아카이브·원본이 노출되지 않고, 일반 직원의 삭제는 거부되며, ZIP의 출처와 포함 파일을 검증할 수 있게 만든다. ZIP 수동 배포와 기존 자산 소유 계정을 유지한다.

PR #11 운영 수정, #24 가격 검사, #25 GEO-004 보고서는 이 지시 작성 시 열린 상태다. #24의 110개 테스트는 벤이 재실행해 통과했으나 운영 고지 전환과 별개다. #25의 시험 자산 상태는 지오 보고 근거이며 역할별 검증은 미실행이다. 벤이 기존 PR의 검토·통합을 담당한다. 담당자는 선행 PR을 임의로 병합하지 않는다.

## CLAUDE-008 완료 조건

- 기존 ZIP 이름·배포 경로·함수 구조를 보존한다. 운영 설정이나 실제 키를 읽어 시험하지 않는다.
- .env 및 변형, 개인 키/인증서 키, 자격증명 파일, VCS·임시·테스트·증거·원시 자료의 포함을 차단한다. 단순 확장자 차단만 믿지 말고 필요한 게시 파일/함수/설정의 허용 범위를 정의한다. 필수 공개 config.js와 비밀 서버 설정을 구별한다.
- 누락된 필수 설정은 명시적으로 실패한다. 더미 설정을 운영 ZIP에 자동 삽입하지 않는다. 링크/재분석 지점으로 프로젝트 밖 파일이 들어오지 않도록 한다.
- 공개 가능한 배포 표식에는 전체 commit SHA, 프로젝트 구분, 파일 해시 목록의 형식 버전을 기록한다. 계정명·로컬 절대 경로·환경변수는 넣지 않는다. dirty checkout은 기본 실패시키고 외부 공개 설정의 해시는 별도 추적한다.
- 최종 ZIP SHA-256은 ZIP 밖 검증 보고서에 기록한다. ZIP 자체 해시를 그 ZIP 안에 넣는 순환 구조를 만들지 않는다.
- 합성 폴더로 정상 파일 보존, 중첩/대소문자 비밀 파일 제외, 누락 설정 실패, 경로 이탈 차단, SHA 표식 일치, 두 프로젝트 패키징을 시험한다. sentinel 가짜 비밀값만 사용한다.
- 배포는 하지 않는다. CLAUDE-007 가격 승격은 #11/#24 통합 후 별도 진행한다. 먼저 완료한 담당자가 전체를 기다리지 않도록 독립 PR을 제출한다.

## ANT-003a 설계 계약

현행 04 API는 ACCESS_CODE가 없으면 인증을 생략하고 config 응답은 인증 전에 sheetUrl을 반환한다. 01 클라이언트 게스트 모드만으로 서버 권한을 보장할 수 없다. 실제 서버 계약을 읽고 파일/함수 근거로 설계한다.

권장 흐름: 직원 로그인 → 서버가 검증하는 세션/토큰 → 서버 역할 검사 → 업무로그/비공개 Drive 제공. Netlify 함수와 기존 인증 재사용을 우선 평가하되 현행 서비스의 지원·비용·제한은 공식 문서로 확인하고 출처/확인일을 남긴다. 새 유료 서비스나 소유권 이전을 전제로 하지 않는다.

| 행위 | 미인증/비직원 | 직원 | 관리자 |
|---|---|---|---|
| 원장·목록·썸네일·원본 조회 | 거부 | 허용 | 허용 |
| 업무로그 저장·업로드 | 거부 | 허용 | 허용 |
| 삭제 | 거부 | 거부 | 허용 대상(휴지통/영구삭제 방식은 미확정) |
| 직원 권한 부여/변경 | 거부 | 거부 | 지정 관리 절차 필요 |

- 신원 검증과 역할 부여를 분리한다. 자가가입만으로 직원이 되거나 클라이언트 admin 플래그로 권한이 생기면 안 된다. 일반 직원에게 관리자 계정/공용 비밀번호를 공유하지 않는다.
- 쿠키 사용 시 CSRF/Origin 검증, 토큰 사용 시 저장·만료·철회, 로그아웃 시 브라우저 캐시와 서비스 워커까지 다룬다. 민감 응답은 공유 캐시에 남기지 않는다.
- 파일 ID 조작으로 범위 밖 Drive 자료를 읽지 못하도록 서버에서 허용 루트/자산 범위를 검사한다. 썸네일/다운로드 응답이 공개 우회 링크를 누출하지 않도록 한다.
- 기존 GAS의 무인증 URL과 업로드 시 공개 공유를 거는 경로를 어떻게 차단할지 적는다. 프록시만 추가하고 기존 공개 GAS를 열어두는 설계는 불합격이다. 웹 앱 실행 주체와 호출자 인증은 별도로 검증한다.
- 예약·동의서 등 고객 공개 화면은 유지하면서 직원 API/캐시를 분리한다. 기존 11분류와 원본 자료를 보존하고 복사·재적재하지 않는다.
- 두 실사용 도메인의 인증/로그아웃 경계를 설명한다. 내부 아카이브를 표준 입구로 하고 구 입구의 API 우회를 차단한다.
- 변경 순서, 합성 환경 검증, 운영 ZIP/서버 적용, 차단 상태 복구를 분리한다. 이전 공개 버전 재배포가 접근 통제를 되돌리지 않도록 한다.
- 산출물: 권한표, 요청 흐름, 변경 파일 목록, 설정 이름만 담은 템플릿 계획, 위험·비용·미확정 선택, 테스트 및 배포 순서. 이번은 문서 PR이며 DB/GAS/Netlify 운영 변경 금지.

## GEO-005 지금 가능한 준비

기존 시험 폴더·시트·빈 GAS를 재생성하지 않는다. 기존 비공개 시험 폴더에 개인정보 없는 합성 이미지 3개와 분류/검색/미리보기 시험표를 준비한다. 새로운 공유·배포·가입은 하지 않는다. 합성 이미지 제작 도구가 없으면 시험표에 필요한 특성만 정리하고 이미지 생성 미실행을 표시한다.

미인증/허용 직원/관리자/권한 없는 기존 계정의 예상 결과를 URL 직접 접근, 파일 ID 변경, 만료, 로그아웃, 뒤로가기/캐시, 업로드 후 공유 상태로 나눠 기록한다. 실제 결과 칸은 실행 전 비워둔다. 관리자 삭제는 정책 확정 전 영구삭제를 가정하지 않는다.

대표의 시험 계정 지정 답변은 아직 없다. 이는 운영 직원 명단 승인과 별개다. 답변 전 시험 계정을 공유 대상에 추가하지 않는다. ANT-003a 검토와 실제 시험 코드/환경 준비 전에는 역할별 성공을 보고하지 않는다. 운영 자산의 공개 링크 해제는 직원 대상 확인까지 계속 보류한다.

## 실행 시간과 인수 기준

각 보고에 시작/제출 시각(KST), 실측 가능한 작업·대기 시간, 재작업, 완료/미실행, 최종 SHA와 PR을 적는다. 과거 시간이나 도구 대기를 실제 작업 시간으로 추정하지 않는다. 작은 독립 단위로 먼저 제출하고 시간이 남으면 벤에게 다음 배정을 요청한다.

브라우저 시험은 단계별 제한 시간과 전체 종료 제한을 둔다. 기본 단계 30초/전체 5분, 한 번 진단 재시도 후 같은 정체면 원인·로그를 제출한다. 자식 프로세스는 자신이 시작한 것만 정리한다. 이 제한을 일반 설계·구현 시간 제한으로 해석하지 않는다.

벤은 PR #25 문서 통합, #24 검사 통합, #11 주문·취소·안전·마감 검증을 각각 판단한다. 코드 통합은 운영 배포와 다르다. 이 지시는 실행 가능한 후속 준비를 배정하며 실제 계정 공유·운영 배포 승인으로 확대하지 않는다.
