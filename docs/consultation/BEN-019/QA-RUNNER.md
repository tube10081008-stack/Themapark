# 독립 대화 검증 실행

이 도구는 벤/GEO-007 소유다. 아난티의 런타임 코드와 별개로 실행한다.

```powershell
node docs/consultation/BEN-019/runner.test.mjs
node docs/consultation/BEN-019/run-conversation-evals.mjs --endpoint http://127.0.0.1:4173/.netlify/functions/consult --sha <구현 전체 SHA> --out <새 결과 JSON 경로> --cases CS-009,CS-010,CS-011
```

원격 미리보기 시험은 --live를 명시하고 HTTPS 상담 함수 URL을 사용한다. 이 옵션은 실제 모델 호출·사용량이 발생할 수 있다는 실행 구분이다. 기본은 로컬 전용이며 원격을 추측해서 실행하지 않는다. 키를 인수나 URL에 넣지 않는다. 비용 있는 전수 시험 전 소수 시나리오로 연결을 확인한다.

출력 결과는 덮어쓰지 않는다. 외부 결과 파일은 outputs 등 저장소 밖에 둔다. 실제 고객 데이터를 suite에 넣지 않는다.

- 각 시나리오는 빈 문맥으로 시작한다. 다중 턴은 실제 직전 응답만 다음 요청에 넣는다.
- 원격은 요청 사이 7초 간격, 요청당 15초 제한, 전체 10분 예산. 남은 시험은 미실행으로 기록한다. 별도 트래픽으로 429가 발생하면 실패로 기록하며 자동 재시도하지 않는다.
- fixture(저장소 장애·한도·오프라인·위조 역할)는 일반 endpoint 실행에서 건너뛰고 격리 시험/브라우저에서 수행한다.
- HTTP 200은 품질 통과가 아니다. action/knowledge_ids 대조와 model 사용 여부는 진단 정보이며 의미·말투는 사람이 채점한다. 결과는 needs_review이며 자동 quality_passes는 항상 0이다.
- 개인정보 제거는 애플리케이션 검증 대상이다. 이 도구는 합성 질문 원문을 요청하므로 실제 개인정보를 사용하지 않는다.
- 5개 자체 시험은 실행 도구의 대화 격리·실제 답변 연결·장애·시간/길이·원격 호출 제약을 검증한다. 챗봇의 품질 시험 40개 통과로 세지 않는다.
