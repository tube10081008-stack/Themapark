## 4. 시험표

판정 표기:
- **합격**: 기준을 충족한다.
- **불합격**: 기준을 위반한다.

- **실행 불가**: 환경 문제로 실행하지 못했다. 사유를 함께 적는다.

### 4-0. 벤 확정 기준 상세 시나리오 (K1~K6)

**증거 수집 공통 규칙**
- **E-SHOT:** 단말별 화면 캡처. 이름·전화·토큰·ID 영역은 저장 전에 가린다. 파일명은 `GEO008_<시험ID>_<단말>_<HHMMSS>.png`.
- **E-NET:** 브라우저 개발자도구 네트워크 기록(HAR). 해당 RPC의 요청 본문, 응답 코드, 응답 본문을 남긴다. 토큰·ID·개인정보 값은 `[MASK]`로 치환한 사본만 보관한다.
- **E-DB:** 시험 DB에서 `ticket_queue`의 상태 열(`queue_number, status, order_key, desk_no, restored_at, completed_at`)만 읽기 조회해 기록한다. 개인정보 열은 조회하지 않는다. 시험 DB 읽기 권한이 없으면 직원 목록 RPC 응답(E-NET)으로 대체하고 그 사실을 적는다.
- **E-TIME:** 각 조작의 KST 시각(초 단위)과 화면 반영 시각. 반영 지연은 폴링 주기(현재 구현 3초)와 비교한다.
- 원본 증거는 저장소에 넣지 않는다. 보고에는 마스킹한 요약 수치만 적는다.
