# GEO-008 — 발권 대기 시스템 실사용 검증 시험표

작성: 지오(Aside), 2026-10-08. 기준 origin/master `892a06143ebe69e64a77761cd5793ab199c9755b`, 브랜치 `aside/GEO-008-ticket-queue-qa`. 지시: 벤 → 지오 GEO-008 메시지(2026-10-08, 대표 경유 전달). 이 지시서는 저장소에 아직 없다.

**이 문서는 실행 전 준비 문서다.** 실제 결과·판정 칸은 모두 비워 두었다. 대기열 기능은 아직 저장소에 구현되지 않았다. 따라서 모든 시험의 현재 상태는 **"구현 인계 대기"**이며, 실패로 처리하지 않는다. 아난티가 합성 시험 URL·시험 계정·판본 SHA를 제출하고 벤이 인계하면 실행한다.

## 0. 작업 경계

- 운영 사이트는 읽기만 한다. 실제 동의서·접수·결제·대기 데이터를 만들지 않는다.
- 코드·DB·공유 권한·배포 설정을 변경하지 않는다. 이번 변경은 이 문서와 작업표의 GEO-008 행뿐이다.
- 증거 화면에는 이름·전화번호·자녀 정보·서명·조회 토큰·계정·URL·키가 보이지 않게 한다. 시험 데이터도 합성 값만 쓴다.

## 1. 대상 기능 (지시 기준)

- QR 동의서가 서버에 접수된 순서대로 **1건 = 1팀** 대기번호를 부여한다.
- 고객 화면: 내 번호, 상태, 앞선 미발권 팀 수, 예상시간, 마지막 갱신 시각.
- 매표 직원 화면: 번호 호출. 발권을 완료하면 대기에서 제외한다.

## 4. 시험표

판정 표기:
- **합격**: 확인 기준을 충족한다.
- **불합격**: 확인 기준을 위반한다.
- **구현 인계 대기**: 화면이나 기능이 아직 없다. 실패로 집계하지 않는다.
- **실행 불가**: 환경 문제로 실행하지 못했다. 사유를 함께 적는다.

실제 결과 칸에는 관찰 시각(KST), 대기번호, 앞선 팀 수, 화면 문구, 요청 수만 적고 개인정보는 적지 않는다.
