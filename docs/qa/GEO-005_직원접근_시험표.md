# GEO-005 — 직원 접근 합성 시험표

작성: 지오(Aside), 2026-10-02. 기준 origin/master `edb6f62238d092a2374b3f8d9103331be59232dc`, 브랜치 `aside/GEO-005-access-test-matrix`. 지시: [BEN-013](../tasks/BEN-013_직원접근설계와_배포보강.md) "GEO-005 지금 가능한 준비". 입력: [GEO-003](GEO-003_내부아카이브_통합대조.md), GEO-004(PR #25, 미병합).

**실행 전 준비 문서다.** 실제 결과·판정 칸은 모두 비워 두었다. 역할별 성공·실패는 보고하지 않는다. ANT-003a 설계 검토와 시험 코드·환경이 준비된 뒤 실행한다. 작성 시점에 `antigravity/ANT-003a-staff-archive-design` 브랜치는 없었으므로, 설계에 따라 달라지는 칸은 "설계 대기"로 표시했다.

## 0. 경계

- 기존 시험 폴더·시트·빈 GAS는 다시 만들지 않았다. 합성 이미지 3개만 기존 비공개 시험 폴더에 추가했다.
- 새로운 공유·배포·가입은 없다. 대표의 시험 계정 지정 답변이 없으므로 시험 계정을 공유 대상에 추가하지 않았다.
- 운영 자산(공유·GAS 배포·Netlify·시트)은 변경하지 않았다. 운영 공개 링크 해제는 직원 대상 확인까지 계속 보류한다.
- 계정 주소, 파일·공유 URL, Drive/GAS/시트 식별자, 직원 명단, 비밀값은 이 문서에 적지 않는다.

### 합성 이미지

생성 도구는 Aside 이미지 생성이다. 생성 지시에 사람·얼굴·로고·실제 장소·추가 문구 금지를 넣었고, 생성 후 세 장 모두 사람·얼굴·실제 장소·개인정보가 없는지 육안으로 확인했다. 파일에 메모·작성자 같은 Drive 설명은 넣지 않았다.

## 2. 시험 설계 입력: 현행 서버·화면 계약 (master `edb6f62` 소스 기준)

| 영역 | 현행 동작(근거 파일) | 시험 영향 |
|---|---|---|
| 01 직원 게이트 | 공용 접근 코드를 Supabase RPC `verify_staff_access`로 검증한다. 통과하면 코드 원문과 만료 시각을 localStorage `bongplay_staff_session_v2`에 저장한다(기본 12시간, `STAFF_SESSION_HOURS`). 로그아웃은 이 키를 지우고 새로고침한다. (`assets/config.template.js`) | 개인별 신원이 없어 직원·관리자 구분이 현재 불가하다. 역할 시험은 ANT-003a의 신원·역할 분리 설계가 필요하다 |
| 01 내부 아카이브 | GAS를 `ping`·`folders`·`list`·`createFolder`·`upload`·`delete` 동작으로 호출한다. 목록은 localStorage `bongplay_archive_cache_v1`에 캐시하고, 작성자 이름도 localStorage에 저장한다. 검색 대상은 메모·작성자·파일명이다. 화면 기본 분류는 5개이고, 나머지는 Drive 폴더를 자동 인식한다(운영 Drive 11개, GEO-003/004 관찰). 라이트박스에 삭제 버튼이 있고, 삭제는 휴지통 이동이다. (`pages/archive.html`) | 로그아웃·만료 시 캐시 삭제와 서버 측 삭제 거부를 따로 시험해야 한다 |
| 라이브와 소스 차이 | 2026-10-02 공개 응답 기준 라이브 `pages/archive`에는 삭제 버튼 표식이 없고 캐시 키는 있다. 라이브 배포는 master보다 이전이다(GEO-004). | 실행 시 시험 대상 SHA를 먼저 기록한다 |
| GAS 아카이브 | 운영 웹 앱은 "소유자 실행·모든 사용자 접근"이다. 호출자 인증이 없고, 업로드·폴더 생성 때 링크 공유를 설정한다(GEO-004, 2026-10-01 관찰). | 기존 URL 직접 호출 거부와 업로드 후 공유 상태가 필수 시험이다 |
| 서비스 워커 | GAS 호스트, `/api/`, `/.netlify/`, 비GET 요청은 개입하지 않는다. 같은 출처 HTML/JS는 네트워크 우선이며 200 응답을 Cache Storage에 저장한다(`archive.html`, `config.js` 포함). 로그아웃 시 Cache Storage는 지우지 않는다. (`sw.js`) | 오프라인·뒤로가기 시험에서 화면 껍데기와 자료 노출을 구분해야 한다 |
| 04 업무로그 API | `config`는 인증 없이 `sheetUrl`을 반환한다. `classify`·`append`·`diag`·`rows`·`format`은 `ACCESS_CODE`가 없으면 검사를 생략한다(운영에는 미설정, GEO-004). 응답 헤더는 `cache-control: no-store`다. (`netlify/functions/api.mjs`) | 무인증 호출 거부와 `sheetUrl` 비노출을 시험한다 |

## 5. 접근 통제 시험표

표기:
- **허용**: 자료가 정상 반환된다.
- **거부**: 401/403 또는 로그인 요구가 나오고, 자료·썸네일·원본 링크가 0건이다.
- **설계 대기**: ANT-003a 확정 뒤 예상 결과를 기입한다.

실제 결과 칸에는 응답 코드, 자료 건수, 네트워크 요청 수를 적는다.

## 6. 실행 조건

- **선행 조건(모두 미충족)**:
  - ANT-003a 설계 검토
  - 시험 GAS 코드·배포
  - 시험 폴더 하위 구조(분류 A·B·C, 범위 밖)
  - 대표의 시험 계정 지정과 그 계정에 대한 최소 공유
  - (E-02) 시험 화면 배포처 승인
- **브라우저 시험 제한(BEN-013)**:
  - 단계별 30초, 전체 5분
  - 한 번 진단 재시도 후에도 같은 정체가 나오면 원인과 로그를 제출
  - 자식 프로세스는 직접 시작한 것만 정리
- **기록**:
  - 실제 결과 칸에 응답 코드, 자료 건수, 요청 수, 관찰 시각(KST)을 적는다.
  - 증거 화면에는 계정 주소·URL·ID가 보이지 않게 한다.
  - "설계 대기" 칸은 실행 전에 예상 결과를 먼저 확정한다.

## 7. 추가 관찰 (값 미기재, 벤 판단 요청)

- 공개 배포 파일 `assets/bongplay-site.js`(01)에 직원 배열(이름·직함·연락처 필드)이 있다. 2026-10-02 라이브 응답에서 휴대전화 형식 번호 5건을 확인했다. 직원 전용 목표와 별개로, 공개 파일의 개인 연락처를 어떻게 처리할지 결정이 필요하다. 값은 기록하지 않았고 파일은 수정하지 않았다.
- 현행 직원 게이트는 공용 코드 하나라서, BEN-013의 "일반 직원에게 공용 비밀번호를 공유하지 않는다"와 직원·관리자 분리를 만족하려면 개인 단위 신원이 필요하다(ANT-003a 입력).
