### 2.1 면적 확정 근거
- **924.0㎡**: 놀이동 건물 연면적 (건축물대장 1p 기준)
- **657.785㎡ (약 199평)**: 실내놀이시설장 면적 (시설명세 세부내역서 기준)

### 2.2 코드베이스 반영 및 하위 호환성 유지
1. `01_봉플레이_운영시스템/assets/bongplay-site.js`:
   - `SITE.area` SSOT 객체 신설:
     ```javascript
     area: {
       building_gross_sqm: 924.0,       // 놀이동 건물 연면적 924㎡
       indoor_play_sqm: 657.785,        // 실내 놀이공간 657.8㎡
       indoor_play_pyeong: 199          // 약 199평
     }
     ```
   - 전역 헬퍼 `BongplaySite.area()` 노출.
2. `01_봉플레이_운영시스템/assets/bongplay-id.js` & `assets/bongplay-id-core.js`:
   - `MASTER_FACILITIES.play_dome` 내 필드 분리:
     - `building_area_sqm: 924.00`
     - `play_area_sqm: 657.785`
     - `area_sqm: 924.00` (기존 전역 참조 코드 호환성을 위해 유지)
   - `MASTER_PRODUCTS.PROD_CHILD_BASIC_STD` 상품 설명 갱신:
     - `'놀이동(연면적 924㎡ / 실내 놀이공간 657.8㎡) + 야외 네트어드벤처 2시간 정규 고시가'`
3. `01_봉플레이_운영시스템/pages/booking.html`:
   - 단체 예약 요금 안내 문구 수정: `'실내 놀이공간 657.8㎡(약 199평) + 센트럴 네트 (정가 15,000원 고시)'` 반영, 고객에게 놀이공간 전체가 924㎡인 것처럼 오인되지 않도록 차단.

## 5. 결함 등록부 (Defect Register)

### [P0-1] 공용 키오스크/태블릿에서 타 고객의 개인정보(서약서) 노출 결함
- **심각도**: P0 (데이터 유출 및 개인정보보호법 위반 위험)
- **대상 파일**: `01_봉플레이_운영시스템/pages/consent.html` (577~595행)
- **재현 경로**:
  1. 공용 패드에서 앞 손님이 서약서 작성 완료 후 제출.
  2. 다음 손님이 휴대폰 번호 4자리를 입력할 때 `checkRepeatFamily`가 로컬스토리지의 `bongplay_safety_consents` 배열을 검색하여 앞선 타인의 가족 성명과 자녀 목록을 화면에 자동 완성하여 표시함.
- **근본 원인**: 재방문 자동완성 로직이 해당 기기의 전체 서약 내역 배열을 조회하는 취약한 폴백 코드를 포함하고 있었음.
- **수정 내용**: `bongplay_safety_consents` 조회 폴백을 완전히 제거하고, 동일 번호 전용 로컬 캐시(`bongplay_family_${digits}`) 또는 서버 RPC 보안 함수(`lookup_family_children`)만을 조회하도록 제한.
- **검증**: `operations_integrity.test.js` 테스트 6 통과.

### [P1-1] 봉아카이브 업로드 시 작성자 이름 입력 시 카테고리 리셋 결함
- **심각도**: P1 (실제 사용자 보고 결함, 업무 기록 분류 손상)
- **대상 파일**: `01_봉플레이_운영시스템/pages/archive.html` (536~544행, 630~640행, 673~683행)
- **재현 경로**:
  1. 봉아카이브에서 업로드 카테고리를 '캐릭터'로 선택.
  2. 작성자 입력란에 '김지연'을 입력하거나 백그라운드에서 `loadMediaList()`가 주기적으로 실행됨.
