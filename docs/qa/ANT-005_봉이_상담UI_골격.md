## 2. 주요 구현 내용

### 2.1 페르소나 반영 및 UI 골격 구현 (`consultation.js`, `consultation.css`)
- **타이틀 및 캐릭터**: `봉플레이 AI 방문 도우미 봉이 🌿` 표기 적용.
- **첫 진입 안내 문구**:
  `"안녕하세요, 봉플레이 AI 방문 도우미 봉이예요 🌿 이용권부터 단체 방문 준비까지 함께 살펴볼게요. 어떤 점이 궁금하세요?"`
  (상담 모달 오픈 시 로그가 비어있으면 봇 메시지로 즉시 렌더링).
- **개인정보 안내문 최신화**:
  `"전화번호·이름·예약번호 등 개인정보는 입력하지 마세요. 질문과 최근 대화 일부가 Sakana 등 AI 공급자로 전송될 수 있습니다."`
- **빠른 주제 버튼 연동**: '요금', '운영시간', '위치', '시설', '예약', '단체' 6개 버튼 유지 및 제로 비용 안내 제공.

### 2.2 '새 대화' 리셋 및 비동기 경쟁 방어
- **새 대화 버튼 추가**: 헤더 우측에 `.consult-reset-btn` 배치.
- **대화 세대 ID (generation ID)**: 세대 번호를 관리하여 사용자가 '새 대화'를 누른 후 지연 도착한 이전 요청 결과가 새 대화 화면에 섞여 들어가지 않도록 자동 폐기.
- **요청 즉시 취소**: 새 대화 클릭 시 진행 중인 통신을 `AbortController.abort()`로 즉각 중단.
- **초기화 동작**: 브라우저 메모리 대화 이력 배열 초기화, 로그 창 비우기 및 첫 인사 복원.

### 2.3 대화 기억 (In-Memory Conversation History) 무결성
- **브라우저 메모리 격리**: 최근 6개 발화(사용자·상담사 합계)만 자바스크립트 런타임 메모리 배열에 보관.
- **영속 저장소 오염 0건**: `localStorage` 및 `sessionStorage`에 대화 이력을 일체 기록하지 않음.
- **용량 상한 제어**: 건당 최대 800자, 전체 합계 최대 3,200자 초과 시 오래된 발화부터 슬라이딩 제거.
- **실패 응답 격리**: 서버 장애, 타임아웃, 오프라인 시 실패한 assistant 응답을 대화 이력에 추가하지 않음.

### 2.4 서버 사이드 대화 이력 정제 (`rate-limit.mjs`, `consult.mjs`)
- `sanitizeHistory(history)` 함수 구현:
  - 역할 승격 시도 원천 차단: `system`, `developer`, 기타 임의 역할을 거부하고 `user`, `assistant`만 허용.
  - 개인정보 패턴 필터링: 전화번호(`010-`, `+82`), 이메일, 주민등록번호가 포함된 발화는 문맥 전달에서 자동 제외.
  - 최대 6개 발화, 건당 800자, 합계 3,200자 초과 방어.

### 2.5 릴리스 허용 목록 검증 (`build-release.mjs`)
- 신규 모듈 추가 시 릴리스 패키징 스크립트의 화이트리스트 무결성을 점검.
