### R1 — P1: 따옴표가 있는 중복 속성으로 요금 불일치가 통과함

파일: `05_봉플레이_AI에이전트/core/price_check.py`, `_keyed_values()`.

실제 JS의 보호자 항목에서 아래 메모리 내 치환 후 `run_checks()` 실행:

```python
mut = js.replace("list_price: 5000,  customer: 'adult'",
                 "list_price: 5000, 'list_price': 6000, customer: 'adult'", 1)
```

결과: `catalog_prices(mut)['tkt_guardian'] == 5000`, 실패 목록 `[]`.
JS에서 뒤의 동일 키는 6,000원으로 덮어쓰지만 현재 정규식은 따옴표가 있는 키를 놓친다. '중복/형식 변경을 실패 처리한다'는 필수 조건을 충족하지 못한다.

요청: 실제 토큰을 구분하는 제한적 정적 파서를 사용하거나 지원하지 않는 구문을 명시적으로 거부한다. 주석·문자열 안 속성, 따옴표/계산 키, spread 등으로 실효 값이 바뀌거나 모호해지면 실패해야 한다. JS 실행은 하지 않는다. 따옴표 있는 중복 키와 실제 값 불일치를 잡는 회귀 테스트를 추가한다.
