# BEN-008 대표 결정과 보완 인계

2026-09-30. 대표가 벤의 세 질문에 직접 답한 결정을 기록한다.

## 확정 결정

1. 업무로그와 아카이브는 **둘 다 직원 전용**이다.
2. 아카이브 표준 입구는 **운영시스템 내부 아카이브**로 통일한다. 기존 봉챗 아카이브를 기준으로 하자는 벤의 권고는 채택되지 않았다.
3. **ZIP 수동 배포를 유지**한다. Git 자동 배포 전환은 배정하지 않는다.

대표는 앞으로 에이전트 작업 완료 여부만 벤에게 전달한다. 벤은 결정 요청·작업 경계·검증 한계를 직접 읽고 대표 판단 사항은 반드시 질문한다. 기술적인 검토·충돌 조정은 벤이 처리한다.

## 적용 방식과 완료 조건

- 직원 전용은 메뉴/화면을 숨기는 것으로 완료되지 않는다. 업무로그 조회·진단·분류·쓰기 및 아카이브 목록·업로드 등 실제 데이터 경로의 접근 통제를 설계하고, 미인증/직원 권한 테스트로 검증한다. 현행 인증 구조와 서버 연동을 먼저 확인한다. 구체적인 운영 자격증명·권한 부여 대상 등 미확정 정책이 필요하면 대표에게 질문한다.
- 지오 GEO-002의 현행 봉챗 아카이브 정상 기능(11개 분류·자료 연결 등)을 내부 아카이브와 대조하여 보존한다. 파일 복사/재적재/구 입구 폐쇄를 먼저 수행하지 않는다. 대표의 내부 입구 선택은 기존 자료 삭제 승인이 아니다.
- 검토된 SHA를 표시하는 배포 기록/ZIP 체크리스트와 복구용 직전 배포를 마련한다. 운영 config·비밀값을 저장소에 커밋하지 않는다. GitHub 병합과 운영 ZIP 배포 완료를 분리 보고한다.
- 구현은 별도 후속 과제로 아난티 우선 배정한다. 현재 ANT-001과 섞어 동시에 04를 수정하지 않는다. 현행 비교·검증은 지오가 지원한다. 실제 배포 전에 산출물·영향·복구 계획이 검토 가능한 상태여야 한다.
