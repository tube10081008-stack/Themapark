## 대표 확정 답변

1. Drive 원본도 직원만 접근하도록 제한한다. 기존 링크만 가진 외부인의 접근 허용을 유지하지 않는다. 실제 권한 변경은 대상/직원 식별/연동 영향/복구 계획을 검토한 뒤 별도 전환 작업으로 수행한다. 지금 운영 권한을 바꾸지 않았다.
2. 일반 직원에게 삭제 권한을 주지 않고 관리자만 삭제를 허용한다. 구체적인 관리자 식별과 서버 검증을 설계해야 하며 UI 버튼 숨김만으로 완료하지 않는다. 영구삭제/휴지통 처리의 세부 정책은 미확정이다.
3. 버스 임차비 지원은 계획 단계이며 금액과 예약 규모 조건은 미확정이다. 대표가 벤에게 지원안 설계를 요청했다. 기존 '군 지원 30~50만 원' 문구의 확정 근거로 해석하지 않는다. 비용은 대표 답변에 따라 봉플레이 자체 판촉비로 부담한다. 군 보조금을 전제하지 않는다.

## 아난티 실행 대기 진단 인계

코드에서 확인한 무기한 대기 가능 경로이며 실제 멈춘 호출은 로그로 확인해야 한다.

- withTimeout의 catch가 session.screenshot을 별도 제한 없이 await한다. 원래 작업 timeout 뒤에도 CDP가 응답하지 않으면 finally 정리까지 못 간다.
- send/sendSession에 응답 timeout 및 WebSocket close/error 시 pending 요청 reject가 없다.
- 브라우저 시작이 session 반환 전에 실패/시간 초과되면 main finally에 자식 핸들이 없을 수 있다. 생성 즉시 소유권을 등록하고 실패 경로도 정리해야 한다.
- 실제 클릭 대신 session.eval로 제품 함수를 부르는 부분은 브라우저 내 함수 시험이다. 클릭 연결/가림/키보드 조작까지 입증한 것으로 보고하지 않는다.

추가 무기한 실행은 중단하고 가장 작은 브라우저 연결→빈 페이지→유한 종료부터 증거를 남긴다. 모든 진단 캡처도 timeout을 갖고, 해당 실행 자원만 정리한다. 단계 실패와 미실행은 그대로 보고한다.
