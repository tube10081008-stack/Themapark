# BEN-017 보호자권 웰컴 음료 안내 결정

2026-10-05 / 대표 직접 지시 기록: 벤이 제안한 '보호자 입장권 5,000원 · 웰컴 음료 1잔 포함' 안내 통일에 대표가 '응 ! 그렇게 맞춰줄래 ?'로 승인했다.

가격은 5,000원 그대로 유지하며 보호자권에 웰컴 음료 1잔 포함을 안내한다. 메뉴, 선택 범위, 교환권 지급 방식, 제공 개시일은 이 결정으로 확정하지 않는다. 따라서 커피/아메리카노/티 선택, 특정 가치의 무료 증정, 실질 입장료 0원 등의 표현을 사용하지 않는다. 이전 문서의 계획 및 과거 고지는 역사 기록으로 보존한다.

변경 대상: 01 예약/현장 POS/시뮬레이터 안내와 상품 표시명, 06 홈페이지 요금표 및 상담 지식 계약. 상품 ID·판매가·할인 계산·결제·재고는 변경하지 않는다. 05 가격 계약은 5,000원을 그대로 유지하며 이번 혜택의 출처는 이 결정문을 사용한다. 음료 발급·소진 추적 시스템은 이번 문구 변경 범위에 포함하지 않는다. 실제 서비스 반영은 후속 배포 시점이다.
