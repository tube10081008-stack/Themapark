## DESIGN.md 9절에 대한 결정

1. **어긋남 감지는 채택, 고객용 confirmed 요금은 경고만으로 통과시키지 않는다.** 004b 범위에서 profile과 현재 고지/카탈로그의 선택된 품목을 대조하는 검증을 둔다. JS를 실행하지 않는다. 정규식만으로 여러 숫자 중 하나를 임의 채택하지 않는다. 정적 분석 또는 범위를 좁힌 추출기를 쓰되 키 중복·형식 변경·추출 실패·값/조건 불일치를 실패로 처리한다. 자동으로 profile 가격을 덮어쓰거나 confirmed로 승격하지 않는다. 공통 assets 변경 없이 05 안에 구현한다.
2. **confirmed 승격은 출처가 있는 PR로 한다.** value, 단위/적용 범위, 원본 경로·항목 및 commit SHA 또는 문서 판본, 확인자와 확인일, 시행일(알려진 경우)을 남긴다. 대표 결정 또는 해당 필드에 적합한 1차 자료를 벤이 검토해 병합한다. 단순한 재생성·코드 존재·출처 변경만으로 승격하지 않는다. 오래된 confirmed와 새 근거가 충돌하면 해당 값은 고객용 출력에서 보류한다. 최초 전달 결정도 위 표의 범위 내에서만 적용한다.
3. **시설 설명도 profile의 확인된 값으로 생성한다.** 짚코스터는 야외 시설이다. BEN-002에서 확인한 시설명세의 외부시설 목록을 출처로 기록한다. '실내 짚라인형'은 이관하지 않는다. 모르는 높이·길이·운영조건은 자동 보충하지 않는다.
4. **기본 모델 ID는 하드코딩하지 않는다.** 원본 `claude-opus-5` 등은 이번 검토에서 실제 계정/API 제공 여부를 확인하지 않았다. 기존 Anthropic 클라이언트를 유지하는 단계에서는 `ANTHROPIC_MODEL`을 명시적으로 받고 미설정이면 LLM 명령만 설명과 함께 종료한다. 순수 계산·계약 검증·mock 테스트는 모델/키 없이 실행 가능해야 한다. 실제 모델 선택과 호출 검증은 연결 계정에서 가능한 ID와 이용 범위를 확인한 후 진행한다. 임의 제공자 전환·유료 호출은 포함하지 않는다.
