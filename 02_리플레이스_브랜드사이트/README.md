## 3. Netlify 즉시 배포 가이드 (배포용 zip 파일 제공)

프로젝트 루트에 Netlify 배포용으로 최적화된 **`replayce_deploy.zip`** 파일이 준비되어 있습니다.

### 초간단 배포 방법 (드래그 앤 드롭):
1. 웹 브라우저에서 **[Netlify Drop (app.netlify.com/drop)](https://app.netlify.com/drop)** 에 접속하여 로그인합니다.
2. 폴더 내 **`replayce_deploy.zip`** 파일을 화면의 점선 박스 안으로 **드래그 앤 드롭**합니다.
3. 약 5초 이내에 무료 SSL 인증서(https://)가 적용된 공식 웹 주소(`https://[랜덤이름].netlify.app`)가 즉시 발급되며 실시간 서비스가 시작됩니다.
4. 필요 시 Netlify 사이트 설정에서 원하는 커스텀 도메인(예: `replayce.kr`)으로 연결할 수 있습니다.
