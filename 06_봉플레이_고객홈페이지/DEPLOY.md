# 고객 홈페이지 Netlify 수동 배포

이 폴더는 2026-10-04 사용자가 제공한 Downloads/bongplay-homepage를 복사한 정적 고객 홈페이지다. 01 운영시스템, 02 기업사이트, 04 업무로그와 별도다. 원본 HTML/CSS/JS/이미지는 변경하지 않았다.

## 배포 대상

고객 홈페이지 전용 Netlify 프로젝트를 사용한다. 기존 bongplay.netlify.app 운영시스템이나 bongplaychat.netlify.app 업무로그 프로젝트에 이 ZIP을 덮어쓰지 않는다. 최종 프로젝트명/도메인은 아직 미지정이며 실제 업로드는 수행하지 않았다. Git 자동 연동 없이 수동 ZIP 배포한다.

ZIP 루트에 index.html, styles.css, app.js, config.js, netlify.toml, assets/, deploy-manifest.json이 있어야 한다. 상위 06 폴더로 감싸지 않는다. 빌드 명령·npm 설치·서버 함수·비밀 환경변수는 필요 없다. Netlify에 사이트 폴더를 지정할 경우 이 폴더를 기준으로 publish `.`를 사용한다.

## 현재 기능과 제한

- 예약 URL 미설정: 전화 문의/방문 계획 복사만 동작하며 실제 예약 접수·결제·재고 연동이 없다.
- 운영시간 미확정 안내 유지. 기본15000/종합21000/보호자5000/20인 이상 단체16800/군민20% 고지.
- config.js는 브라우저 공개 설정이다. API 키/비밀번호를 넣지 않는다.
- AI 홍보 이미지 표시를 유지한다. 실내 보정 이미지와 야외 생성 이미지의 실제 시설 일치 여부는 공개 전 확인 대상이다.
- 원본 README의 /workspace 경로, tests/site-check.cjs 및 review/는 제작자 환경 기록이다. 해당 시험 코드·증거 파일은 전달 폴더에 없으므로 이번 편입에서 제작 당시 검증을 재실행했다고 간주하지 않는다.

## 이번 준비 검증

app.js/config.js 구문 검사, HTML/CSS 로컬 자산 참조 및 앵커, 원본 파일 해시 대조, ZIP 파일 목록·해시를 확인한다. 실제 브라우저 반응형/클립보드/외부 예약 연결 및 Netlify 게시 후 검증은 별도다.

배포 후 첫 화면·이미지·폰트·요금·가족/단체 문의 모달·메뉴·전화·지도·모바일 가로 넘침을 확인하고 Netlify 배포 ID와 ZIP SHA-256을 기록한다. 실패 시 해당 신규 프로젝트의 직전 배포를 복원한다. 첫 배포라면 공개를 중지하고 수정한다.
