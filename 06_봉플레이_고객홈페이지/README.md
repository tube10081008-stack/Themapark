# 봉플레이 고객 홈페이지

리플레이스 기업 사이트와 구분한 방문객용 홈페이지 시안입니다. 기존 Themapark 저장소 밖에 제작하여 다른 에이전트의 코드와 브랜치에 영향을 주지 않습니다.

## 실행

빌드나 npm 설치가 필요 없는 HTML/CSS/JavaScript 사이트입니다.

```bash
cd /workspace/bongplay-customer
python3 -m http.server 8090 --bind 0.0.0.0
```

배포 패키지를 압축 해제해 `index.html`을 브라우저에서 직접 열어도 기본 화면과 예약 안내가 동작합니다. 웹 서버에서는 클립보드 등 브라우저 기능을 더 안정적으로 사용할 수 있습니다.

## 제작 범위

- 모바일 우선 반응형 화면, 하단 고정 예약 버튼, 안전 영역 대응.
- 시설 소개와 상세 팝업, 확정된 이용 요금 안내, 단체 방문, 지도·전화 연결, FAQ.
- 예약 모달: 가족/단체, 희망 방문일, 어린이/보호자 인원 선택.
- 기본 이용권(실내+네트챌린지 2시간) 15,000원, 종합 이용권(기본권+짚코스터 1회) 21,000원을 요금표 상단에 안내. 운영시간은 확인 후 안내.
- 예약 연결 전에는 전화 문의와 방문 계획 복사로 안내. 예약 접수·결제·확정을 가장하지 않음.
- 고객 개인정보 수집 및 DB 쓰기 없음. 방문 선택값은 현재 페이지 메모리에만 유지.
- 사진·아이콘·폰트는 로컬 파일을 사용하며 화면 실행에 외부 CDN이 필요하지 않음.

## 실제 예약 서비스 연결

`config.js`의 공개 설정을 변경합니다. API 키나 서비스 계정 등 비밀값은 넣지 않습니다.

```javascript
booking: {
  familyUrl: 'https://실제-예약서비스/가족-예약',
  groupUrl: 'https://실제-예약서비스/단체-예약',
  queryParameters: { date: '', children: '', adults: '', kind: '' }
}
```

각 URL은 검증된 실제 HTTPS 예약 페이지여야 합니다. 가족/단체 연결은 독립적이며 빈 값이면 해당 유형은 전화 문의로 안내합니다. 현재 URL은 미설정입니다.

예약 서비스가 날짜·인원 전달을 지원할 때에만 공식 파라미터 이름을 `queryParameters`에 지정합니다. 지원하지 않는 서비스에는 임의의 파라미터를 만들지 않습니다. 빈 매핑은 기존 URL과 쿼리를 그대로 유지합니다. 서비스마다 전달 방식이 다르면 어댑터를 해당 계약에 맞춰 보완해야 합니다.

네이버 예약 등의 외부 예약 페이지는 이 홈페이지의 캘린더와 별개로 운영일·판매가격·잔여석·결제·예약확정을 관리합니다. 현재 캘린더는 희망 방문일 선택이며 실시간 예약 가능 날짜를 뜻하지 않습니다.

사이트 내부에서 예약을 직접 접수하려면 별도 서버 API, 상품·운영일·재고·예약상태 계약, 개인정보 처리 및 결제 연동이 필요합니다. 기존 운영 DB에는 연결하지 않았습니다.

## 확인한 정보와 자산

- 시설명·주소·짚코스터·네트챌린지·실내 놀이공간 면적: `05_봉플레이_AI에이전트/site_profile.json`의 확인된 항목.
- 기본권 15,000원·종합권 21,000원: 2026-10-04에 확인한 원격 master의 `01_봉플레이_운영시스템/assets/bongplay-id.js` 상품 카탈로그 기준. 기본권 가격은 같은 경로의 `pages/booking.html` 및 `docs/migration/CLAUDE-004b_대표결정_20260929.md`와 대조. 기존 `site_profile.json`의 미확정 항목이나 운영 데이터는 수정하지 않음.
- 보호자 5,000원, 20인 이상 단체 종합권 16,800원, 봉화군민 우대 20%: 확인된 항목을 사용.
- 전화: 기존 공개 고객 예약 안내 페이지에 게시된 번호.
- 로고: 사용자가 첨부한 레인보우 BONG PLAY 로고를 바탕으로 AI로 배경·시안 번호·설명 문구를 제거한 웹용 투명 이미지. 생성 원본은 `/workspace/generated_images/`에 보관.
- 실내 메인: 사용자가 첨부한 넓은 실내 사진을 바탕으로 AI로 밝기와 선명도를 보정한 이미지. 첨부 파일과 동일한 원본 파일은 아니므로 게시 전 시설 배치의 일치 여부를 확인해야 함.
- 야외 사진: `03_봉뜨락_도면및행정자료/봉뜨락_투자계획서_v4_사진포함.pdf`에서 추출한 실제 짚코스터·네트챌린지 사진을 참조해 AI로 생성한 홍보 이미지. 카드와 상세 안내에 AI 이미지임을 표시. 실제 시설과 차이가 있을 수 있으므로 공개 게시 전 비교 확인이 필요함.
- 이미지 최적화: AI 생성 이미지를 WebP로 인코딩하고 로고만 화면 해상도에 맞게 축소. 야외 사진은 지연 로딩하며 실제 이미지와 생성 원본은 개발 폴더에 유지.
- 폰트: Pretendard 1.3.9를 SIL Open Font License에 따라 페이지에서 사용하는 글자만 포함하고 `Bongplay Sans`로 이름을 변경. 약 2MB에서 76KB로 경량화했으며 라이선스는 `assets/fonts/OFL.txt`에 포함.
- 아이콘·숲 그림: 이 시안을 위해 만든 SVG. 위치 그림은 실제 지도가 아닌 일러스트임을 표시.

기존 사업의 기록을 참고한 시안이므로 운영시간·전화·요금 적용 조건·사진의 최신 상태는 공개 배포 전에 확인해야 합니다.

## 검증

```bash
node tests/site-check.cjs
```

Playwright와 Chromium이 있는 개발 환경에서 실행합니다. 다른 서버 주소는 `BONGPLAY_TEST_URL`, Chromium 경로는 `BONGPLAY_CHROMIUM`으로 지정할 수 있습니다.

320/360/390/430/768/1024/1440px에서 가로 넘침, 폰트·사진 로딩, 레인보우 로고, 기본·종합 요금과 구성, AI 이미지 표시, 메뉴, 캘린더, 인원 증감, 전화 문의 대체 안내, 클립보드, 단체 전환, ESC 종료, 시설 팝업, FAQ를 검증했습니다. 연결 어댑터는 실제 예약을 생성하지 않는 가짜 제공자를 가로채 날짜·인원 전달과 기존 쿼리 유지 여부를 검증했습니다. 실제 예약 서비스 연결 검증은 미실행입니다.

단일 HTML은 로컬 HTTP에서 별도 자산 요청 없이 표시됨을 확인했으며 시설 상세 이미지 3종과 예약 문의 안내를 검증했습니다. 모바일 첫 화면·요금표·체험 카드 및 데스크톱 첫 화면을 별도 촬영해 확인했습니다.

시각 자료와 테스트 결과는 `review/`에 있습니다. 배포용 ZIP에서는 개발 테스트와 검토 이미지를 제외합니다.

기존 Themapark 저장소 수정, 커밋·PR, 운영 배포는 하지 않았습니다.

## 파일 전달

- `preview.html`: 사진·폰트·스타일·스크립트를 내장한 단일 파일. 브라우저에서 열어 시안을 확인할 수 있습니다.
- `/workspace/bongplay-customer.zip`: 실제 정적 사이트 파일을 담은 배포용 패키지. 테스트와 스크린샷은 포함하지 않습니다.
- `python3 tools/package.py`: 수정 후 ZIP과 단일 HTML을 다시 생성합니다. Python 표준 라이브러리만 사용합니다.

폰트 원본은 `tools/font-source/`에 보관하고 배포 ZIP에 넣지 않습니다. 화면 문구에 새 글자가 추가되면 시스템 폰트로 대체되며, 필요시 fontTools와 Brotli가 설치된 환경에서 `python3 tools/subset-font.py`로 폰트를 갱신한 후 다시 패키징할 수 있습니다. 현재 시안 실행에는 해당 개발 도구가 필요하지 않습니다.
