# 업무로그 초안 (초기 적재용)

빈 시트를 처음 채우기 위한 초안입니다. `봉화_리틀포레스트봉뜨락_운영계획서_초안.md` 의
계약 의무·안전 과제·개장 준비 항목을 도구와 같은 A~H 형식으로 옮겼습니다.

| 파일 | 용도 |
|---|---|
| `업무로그_초안.csv` | 구글 시트 **가져오기**용 (UTF-8 BOM, 엑셀에서도 안 깨짐) |
| `업무로그_초안.tsv` | 복사해서 시트에 **붙여넣기**용 |

**51건** — 결정 10 / 할일 27 / 공유 8 / 아이디어 6, 담당자는 성현 22 · 지연 14 · 주성 11 · 공통 4.

## 넣는 법

**A. 가져오기 (빈 시트에 권장)**
파일 → 가져오기 → 업로드 → `업무로그_초안.csv` →
가져오기 위치 **현재 시트 바꾸기**, 구분 문자 **쉼표** → 데이터 가져오기.
시트 탭 이름은 `업무로그` 로 바꿔주세요(도구가 그 이름으로 씁니다).

**B. 붙여넣기**
`업무로그_초안.tsv` 를 열어 전체 복사 → 시트 A1 에 붙여넣기.

이후 도구에서 들어오는 행은 이 아래에 계속 쌓입니다.

## 쓰기 전에 확인할 것

- **마감일은 개장일을 11월 중순으로 가정하고 역산한 값**입니다. 개장일을 확정하면
  `[결정] 개장일 확정` 건을 먼저 처리하고 나머지 마감일을 조정하세요.
- 사용료 47,300,000원(VAT 포함)과 손익분기 연 17,442명은 계획서의 값이며,
  실제 계약서·견적으로 대체해야 합니다.
- 인허가 항목(유원시설업 등록, 다중이용업소 신고)은 봉화군 담당 부서에 실제 요건을
  확인한 뒤 마감일을 다시 잡으시길 권합니다. 계획서의 일정은 예시입니다.
- 상태는 대부분 `대기` 로 두었고, 이미 움직이고 있을 법한 몇 건만 `진행` 입니다.
  실제와 다르면 시트 G열에서 바꾸세요.
